═══════════════════════════════════════════════════════════════════
    ❌ CANNOT CHANGE (Technical - Will Break)
═══════════════════════════════════════════════════════════════════

1. VARIABLE NAMES (JavaScript)
────────────────────────────────────────────────────────────────────
DON'T CHANGE:
const scienceQuestions = { ... }  // Keep 'scienceQuestions'
const subjectQuestionBank = { ... }  // Keep exact name
function selectSubject() { ... }  // Keep function name

WHY: Code references these exact names


2. SUBJECT KEYS (Object keys)
────────────────────────────────────────────────────────────────────
DON'T CHANGE:
const subjects = {
    science: { ... },  // Keep 'science' key
    math: { ... }      // Keep 'math' key
};

CAN CHANGE:
const subjects = {
    science: { name: 'Vigyan', ... },  // ✓ Change display name
    math: { name: 'Ganit', ... }       // ✓ Change display name
};

WHY: Keys link questions to subjects


3. HTML IDs & CLASSES
────────────────────────────────────────────────────────────────────
DON'T CHANGE:
<div id="subjectGrid">  // Keep exact ID
<div class="subject-card">  // Keep exact class

WHY: JavaScript uses these to find elements


4. FILE STRUCTURE
────────────────────────────────────────────────────────────────────
DON'T CHANGE:
- Load order (questions before master app)
- Priority numbers (10-20 order)
- Script tag structure

WHY: Breaks functionality

METHOD 1: Find & Replace (Easy)
────────────────────────────────────────────────────────────────────

1. Open file in text editor (VS Code, Notepad++)
2. CTRL+H (Find & Replace)
3. Find: "Start Quiz"
4. Replace: "क्विज सुरु गर्नुहोस्"
5. Replace All
6. Save

→ Changes all occurrences! ✓


METHOD 2: Manual Edit (Precise)
────────────────────────────────────────────────────────────────────

1. Open file
2. Search for specific text (CTRL+F)
3. Edit that exact location
4. Save

→ Change only what you want! ✓
