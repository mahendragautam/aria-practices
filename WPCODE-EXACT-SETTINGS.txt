═══════════════════════════════════════════════════════════════════
    WHY SITE WIDE FOOTER (NOT HEADER)?
═══════════════════════════════════════════════════════════════════

HEADER vs FOOTER:

Site Wide Header:
  → Loads in <head> section
  → Runs BEFORE page HTML loads
  → Can cause errors if HTML not ready
  ❌ Not recommended for quiz

Site Wide Footer:
  → Loads before </body> tag
  → Runs AFTER page HTML loads
  → HTML elements available
  ✓ Perfect for quiz!

Example:

<!-- Site Wide Header loads here -->
<html>
<head>
  <title>Page</title>
  <!-- Header JS loads HERE ❌ (too early!) -->
</head>
<body>
  <div class="home-page">...</div>
  <div class="quiz-page">...</div>

  <!-- Site Wide Footer loads here -->
  <!-- Footer JS loads HERE ✓ (perfect timing!) -->
</body>
</html>
