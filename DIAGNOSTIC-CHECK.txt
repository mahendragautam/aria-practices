================================
COMMON PROBLEMS & SOLUTIONS:
================================

PROBLEM 1: "scienceQuestions is not defined"
SOLUTION:
- Science snippet priority MUST be 10
- Master app priority MUST be 20
- Both must be in FOOTER

PROBLEM 2: "currentSubject already declared"
SOLUTION:
- You have DUPLICATE snippets running!
- Delete old/duplicate Master App snippets
- Keep only ONE Master App snippet

PROBLEM 3: "GET undefined/"
SOLUTION:
- Old code is still running
- Update Master App snippet with NEW code
- Make sure you copied the ENTIRE snippet-11-master-app.js
