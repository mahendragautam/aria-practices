QUESTION: Sabai pages ma load garne ki specific page ma matra?

TWO OPTIONS:

────────────────────────────────────────────────────────────────────
OPTION 1: SITE-WIDE (SIMPLE) ⭐ RECOMMENDED FOR BEGINNERS
────────────────────────────────────────────────────────────────────

Configuration:
✓ Location: Auto Insert > Footer
✓ Run: Everywhere
✓ No conditions needed

Pros:
+ Simple setup
+ Works immediately
+ No page configuration needed

Cons:
- Loads on ALL pages (even where quiz not needed)
- Slower page load on other pages
- ~110 KB extra code on every page

Use this if:
→ Quiz is main feature of site
→ Want simplest setup
→ Don't mind loading on all pages

WPCode Settings:
┌─────────────────────────────────────┐
│ Location: Auto Insert > Footer      │
│ Run: Everywhere (default)           │
│ Priority: 10, 11, 12... 20          │
│ Status: Active ✓                    │
└─────────────────────────────────────┘

────────────────────────────────────────────────────────────────────
OPTION 2: PAGE-SPECIFIC (EFFICIENT) ⭐ RECOMMENDED FOR PRODUCTION
────────────────────────────────────────────────────────────────────

Configuration:
✓ Location: Auto Insert > Footer
✓ Run: Only on specific page/URL
✓ Use conditional logic

Pros:
+ Loads ONLY on quiz page
+ Faster site performance
+ No unnecessary code on other pages
+ Better for SEO

Cons:
- Need to configure page condition
- Slightly more setup

Use this if:
→ Quiz is one feature among many
→ Want better performance
→ Professional site optimization

WPCode Settings:
┌─────────────────────────────────────────────────────────┐
│ Location: Auto Insert > Footer                          │
│ Run: Use Smart Conditional Logic                        │
│   → Page: Select "Quiz Page" or enter URL pattern      │
│   → OR URL contains: "/quiz" or "/interactive-quiz"    │
│ Priority: 10, 11, 12... 20                              │
│ Status: Active ✓                                        │
└─────────────────────────────────────────────────────────┘

Example URL Patterns:
→ yoursite.com/quiz → Load snippets
→ yoursite.com/interactive-quiz → Load snippets
→ yoursite.com/about → Don't load
→ yoursite.com/contact → Don't load

────────────────────────────────────────────────────────────────────
COMPARISON:
────────────────────────────────────────────────────────────────────

| Feature          | Site-Wide | Page-Specific |
|------------------|-----------|---------------|
| Setup            | Easy      | Medium        |
| Performance      | Slower    | Faster        |
| Load Time        | +110 KB   | Only on quiz  |
| Best For         | Simple    | Professional  |

────────────────────────────────────────────────────────────────────
RECOMMENDED APPROACH:
────────────────────────────────────────────────────────────────────

START: Option 1 (Site-Wide)
  → Quick setup
  → Test everything works

LATER: Switch to Option 2 (Page-Specific)
  → Better performance
  → Professional optimization

────────────────────────────────────────────────────────────────────
HOW TO SETUP PAGE-SPECIFIC (Step by Step):
────────────────────────────────────────────────────────────────────

1. Create quiz page in WordPress
   → Pages > Add New
   → Title: "Interactive Quiz"
   → Slug: /quiz or /interactive-quiz
   → Publish

2. For EACH snippet (01-11):
   a) WPCode > Edit Snippet
   b) Scroll to "Smart Conditional Logic"
   c) Enable: ON
   d) Add Rule:
      - Show if: Page
      - Is: Your quiz page
      OR
      - Show if: URL contains
      - Value: /quiz
   e) Save

3. Test:
   → Go to quiz page → Snippets load ✓
   → Go to other page → Snippets don't load ✓
