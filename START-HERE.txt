WPCODE COPY-PASTE STEPS (11 times repeat):
────────────────────────────────────────────────────────────────────

For EACH file (snippet-01 to snippet-11):

1. Open file
2. CTRL+A (select all)
3. CTRL+C (copy)
4. WordPress Admin > WPCode > Add Snippet > Add Your Custom Code
5. Settings:
   ✓ Code Type: JavaScript
   ✓ Location: Site Wide Footer (select from dropdown)
   ✓ Load Options:

   OPTION A - SIMPLE (for testing):
     → Location: Site Wide Footer
     → Smart Conditional Logic: OFF
     → Loads on all pages (site-wide)

   OPTION B - EFFICIENT (for production):
     → Location: Site Wide Footer
     → Smart Conditional Logic: ON
     → Show if: URL contains "/quiz"
     → Loads ONLY on quiz page
     → Better performance!

   ✓ Priority: (file number × 1 = priority)
      Example: snippet-01 → Priority 10
               snippet-02 → Priority 11
               snippet-11 → Priority 20
   ✓ Status: Active ✓
6. CTRL+V (paste)
7. Name: Quiz - Science (or Math, History, etc.)
8. Save Snippet
9. Next file!

NOTE: See WPCODE-LOCATION-GUIDE.txt for detailed explanation
