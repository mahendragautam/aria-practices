SUPER EASY! Just add one setting:

3. Click: Edit
4. Scroll to: "Smart Conditional Logic" section
5. Toggle: ON (enable it)
6. Click: "Add New Rule"
7. Select:
   ┌──────────────────────────────┐
   │ Show if: URL                 │
   │ Condition: Contains          │
   │ Value: /quiz                 │
   └──────────────────────────────┘
8. Click: Save Snippet
9. Repeat for all 11 snippets

THAT'S IT! ✅
