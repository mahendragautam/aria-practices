────────────────────────────────────────────────────────────────────────────────
ISSUE: Subjects not clickable
────────────────────────────────────────────────────────────────────────────────

Symptoms:
- Click on subject card, nothing happens
- No chapter selection appears

Diagnosis:
1. Open browser console (F12)
2. Click a subject
3. Look for error: "X is not defined"

Solution:
→ Error shows which snippet is missing
→ Example: "mathQuestions is not defined" = Snippet #2 missing
→ Add that snippet to WPCode
→ Make sure it's Active and Priority is correct

────────────────────────────────────────────────────────────────────────────────
ISSUE: Browser back button exits to previous website
────────────────────────────────────────────────────────────────────────────────

Symptoms:
- Press back button
- Immediately exits quiz app
- Doesn't navigate within app

Diagnosis:
→ snippet-11-master-app.js is OLD version (without browser back)

Solution:
1. Open snippet-11-master-app.js in text editor
2. Search for: "isNavigatingHistory"
3. If NOT FOUND → You have old version!
4. Download latest snippet-11-master-app.js from repo
5. File size should be ~34 KB (old = 31 KB)
6. Replace in WPCode
7. Clear all caches
8. Test again

Verification:
→ Open browser console
→ Type: isNavigatingHistory
→ Should show: false (not "undefined")

────────────────────────────────────────────────────────────────────────────────
ISSUE: Back button shows effect but doesn't navigate
────────────────────────────────────────────────────────────────────────────────

Symptoms:
- Press back, see animation
- Screen doesn't actually change
- Stays on same page

This was fixed in latest update. Solution:
→ Same as above - update snippet-11 to latest version

────────────────────────────────────────────────────────────────────────────────
ISSUE: Page refresh always goes to home
────────────────────────────────────────────────────────────────────────────────

Symptoms:
- Navigate to quiz
- Press F5
- Returns to home page instead of staying

This should work with updated code. If not:
1. Check URL has hash (e.g., #quiz-container)
2. If no hash → Browser back feature not loaded
3. Update snippet-11 to latest version

────────────────────────────────────────────────────────────────────────────────
ISSUE: Random console errors about Cloudflare Rocket Loader
────────────────────────────────────────────────────────────────────────────────

Symptoms:
- Errors mentioning "rocket-loader.min.js"
- Scripts loading in wrong order

Solution:
→ Turn OFF Rocket Loader in Cloudflare
→ Cloudflare Dashboard → Speed → Optimization → Rocket Loader: OFF

Why:
→ Rocket Loader defers JavaScript
→ Breaks loading order (questions must load before master app)

────────────────────────────────────────────────────────────────────────────────

Solution:

Usually not an issue with this app, but if it happens:

2. Check Cloudflare settings (mobile cache)
3. Test in incognito/private mode

────────────────────────────────────────────────────────────────────────────────
